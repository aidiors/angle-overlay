# Руководство пользователя

[English version](USER-GUIDE.md) · [Главная](README.ru.md)

Angle Overlay продлевает линию под указателем мыши до краёв выбранного экрана.
Линия отображается поверх окон и пропускает клики. Изображения обрабатываются на вашем компьютере.

## Установка и запуск

1. Откройте **Releases** на странице проекта в GitHub.
2. В разделе **Assets** скачайте `AngleOverlay-<версия>-windows-x64.zip`.
   Автоматические архивы «Source code» предназначены для разработчиков, а не для запуска приложения.
3. Распакуйте весь ZIP в папку. Оставьте `_internal`, `models` и `assets` рядом с EXE.
4. Откройте **AngleOverlay.exe**. Устанавливать Python или CUDA Toolkit не нужно.
5. Выберите экран в разделе **DISPLAY & LINE**, затем нажмите **Start overlay**.
6. Наведите указатель на линию, которую хотите продлить. Overlay следует за указателем.

Приложение предназначено для Windows x64. Перед использованием GPU обновите драйвер видеокарты.
DirectML требует видеокарту с DirectX 12 и Windows 10 версии 1903 или новее.
Готовая RTX-модель рассчитана на NVIDIA RTX поколений Ampere, Ada и Blackwell.
На других видеокартах NVIDIA можно использовать DirectML или CPU.

## Выбор видеокарты

Для обычного использования оставьте **INFERENCE** в режиме **Automatic**:

- На поддерживаемой NVIDIA RTX приложение пробует оптимизированный RTX runtime.
- На AMD, Intel и других совместимых картах оно пробует вычисления на GPU через **DirectML**.
- Если GPU runtime не запускается, Automatic использует CPU и показывает это в статусе.

Можно явно выбрать **NVIDIA RTX**, **DirectML (AMD / Intel)** или **CPU**.
На ноутбуке с двумя видеокартами выберите нужную в списке **GPU for DirectML**.
При явном выборе GPU ошибка запуска отображается пользователю; скрытого перехода на CPU нет.
Первый запуск RTX может занять больше времени: модель подготавливается для вашей карты.
Дождитесь завершения подготовки.

## Управление

| Горячая клавиша | Действие |
|---|---|
| **Ctrl+Alt+O** | Включить или выключить overlay |
| **Ctrl+Alt+P** | Пауза или продолжение |
| **Ctrl+Alt+Q** | Остановить overlay |

Клавиши работают и при скрытом окне настроек. Если клавишу заняло другое приложение,
окно настроек покажет конфликт. Используйте кнопки или меню трея.

Сверните или закройте окно настроек либо нажмите **To tray**, чтобы убрать его в область
уведомлений. Overlay продолжит работать. Нажмите на значок в трее, чтобы открыть настройки.
Правый клик открывает меню управления. Пункт **Exit** полностью закрывает приложение.

## Экран и внешний вид линии

Выберите экран в **DISPLAY & LINE**. Поддерживаются разные разрешения и масштабы Windows,
портретные экраны и мониторы слева или выше основного.
Линия отображается только на выбранном экране и скрывается, если указатель уходит с него.
При необходимости нажмите **Refresh displays** после изменения конфигурации мониторов.

Нажмите на кнопку цвета, чтобы выбрать цвет линии. Ползунок задаёт толщину **1–12 экранных
пикселей**. Изменения применяются сразу. Цвет `#010203` зарезервирован для прозрачности.
Экран, runtime, видеокарта, цвет и толщина сохраняются автоматически.
При следующем запуске приложения overlay изначально выключен.

## Если что-то не работает

| Проблема | Что попробовать |
|---|---|
| Линия не появилась | Включите overlay, снимите паузу, выберите нужный экран и ненадолго задержите указатель на видимой линии. |
| GPU не запускается | Обновите драйвер. Попробуйте DirectML, другую карту в списке или CPU. |
| Запуск занимает много времени | Дождитесь первой подготовки RTX; последующие запуски используют кеш. |
| Приложение исчезло | Найдите значок Angle Overlay в трее или в меню скрытых значков. |
| Горячая клавиша не действует | Проверьте сообщение о конфликте; используйте кнопки или меню трея. |
| Windows предупреждает об EXE | Приложение не подписано. Скачивайте его только со страницы релизов самого проекта. |

Модель оценивает направление линии и может ошибаться на слабых, неоднозначных или незнакомых
изображениях. Идеальное совпадение на любом рабочем столе или в любом приложении не гарантируется.

Скриншоты обрабатываются в памяти, не сохраняются и не отправляются по сети.
Настройки, журнал и RTX-кеш находятся в `%LOCALAPPDATA%\AngleOverlay`.
Windows capture exclusion исключает overlay из поддерживаемых способов захвата;
другие программы записи экрана могут вести себя иначе.

Подробности реализации: [Техническая документация](TECHNICAL.ru.md).
